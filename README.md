# ops-tools

Small tools I use in day-to-day work as a tech lead. Each folder is separate and has its own README.

| Tool | What it does |
|---|---|
| [uptime-watch](uptime-watch/) | Bash uptime checker on a systemd timer: HTTP, TLS certificates, Cloudflare DNS, MX, TCP. Alerts and recovery messages in Telegram or email. |
| [meetclip](meetclip/) | Local meeting transcripts from OBS recordings with Parakeet. Transcribes only the minutes around markers you set during the call. |

No secrets in this repo. Copy the `*.example` files and fill in your own values.
